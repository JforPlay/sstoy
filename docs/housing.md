# 하우징 Beta

`housing.html`에서 가구 목록과 원본 모델을 사용하는 3D 배치 미리보기를 제공합니다.

- 원본 데이터: Hiro420/StellaSoraData의 DormFurniture, DormRoom, DormRoomSize, DormRoomLayout, Item 및 언어별 이름.
- 표시 대상은 NotShow를 제외한 116종입니다. 목록 아이콘과 3D 모델·텍스처는 설치된 로컬 클라이언트에서 추출합니다.
- 실외는 원본 지형·나무·수풀·차량 장면, 실내는 원본 배경·벽·바닥 모델을 사용합니다. 지면의 네 레이어는 원본 컨트롤 맵으로 합성합니다. 게임 전용 셰이더·조명·바람·애니메이션은 완전히 재현하지 않습니다.
- 빈 공간 드래그로 시점 회전, 우클릭 드래그로 화면 이동, 휠로 확대·축소합니다. 가구는 드래그 이동, R 회전, 방향키 이동, Delete 삭제를 지원합니다.
- 일반 가구·러그·벽 장식을 배치할 수 있습니다. 벽 장식은 좌우 벽과 높이를 지정합니다. 벽지·바닥·고정 시설은 공간당 하나를 적용하며 기본 마감·시설로 되돌릴 수 있습니다.
- L × W를 격자 크기로 해석합니다. 저장·충돌 판정은 기존 X·Y 좌표를 유지하며 화면에서는 XZ 바닥 평면으로 변환합니다. 일반 가구 피벗은 모델 바닥 중앙, 고정 시설과 마감은 원본 피벗을 사용합니다.
- 사각형 기반 겹침 검사를 사용하며 러그와 일반 가구는 겹칠 수 있습니다. 벽은 별도 높이 영역을 검사합니다. 게임의 보유 수량·정밀 충돌·상호작용은 재현하지 않습니다. 200개 제한은 이 도구의 제한입니다.
- 수집 점수는 가구 ID별 CollectionValue를 한 번씩 합한 참고치이며 게임 보상 계산이 아닙니다.
- 각 공간은 housingLayoutV1로 브라우저에 자동 저장합니다. 파일과 압축 URL 해시로 공유할 수 있습니다. 공유 배치는 열기만 하면 기존 저장을 덮어쓰지 않으며 편집·저장할 때 반영됩니다. 기존 2D 배치 파일도 그대로 읽습니다.
- 검증: `node scripts/check-housing.mjs`, `npm run typecheck`, `npm run build`.
- 갱신: 별도 업데이트 폴더의 `update_housing_data.ps1`. 기본 실행은 데이터·아이콘·마감 텍스처·3D 모델을 갱신합니다. `-SkipAssets`는 데이터만 갱신합니다.
- 모델 변환: `scripts/export-housing-models.py --scenes`. Python의 UnityPy, numpy, trimesh, Pillow, lz4가 필요합니다. `--ids 720004 720006`으로 일부만 변환할 수 있습니다. 게임 파일은 읽기 전용이며 네트워크·실행 중인 게임에 접근하지 않습니다.
- 모델 목록은 public/assets/housing/models/manifest.json에 기록합니다. 배경의 미해결 번들 목록에는 효과·빌트인 리소스 참조도 포함되므로 실제 메시 누락 여부는 unresolved 필드와 화면을 함께 확인합니다.
- 가구 목록의 토글로 캐릭터 목록을 전환합니다. 목록 바로 옆 정보 패널에서는 가구와 캐릭터 모두 2D 이미지와 3D 모델을 전환할 수 있습니다. 3D 정보창은 별도의 카메라로 자유 회전·확대·이동하며 배치도 시점에는 영향을 주지 않습니다.
- 캐릭터 미리보기는 설치된 하우징용 SD 캐릭터 10명의 기본 자세를 고정한 3D 모델입니다. 목록 더블클릭 또는 정보 패널의 ‘공간에 표시’로 실내·실외 중앙에 표시합니다. 현재는 가구와 별개의 미리보기로, 배치 저장·공유에는 포함하지 않습니다. 걷기·가구 상호작용은 아직 지원하지 않습니다.
- 캐릭터 변환: `scripts/export-housing-characters.py --all`. 설치된 SD 프리팹만 대상으로 하며 뼈대·바인드 포즈를 적용해 정적 메시를 생성합니다. `--skin 16201 --character 162`처럼 개별 추출도 가능합니다. 목록은 public/assets/housing/models/characters.json입니다.
- 감정·표정은 원본 FacialConfig의 얼굴·눈썹 블렌드 셰이프와 입·특수 눈·홍조 재질을 적용합니다. 모든 표정 파츠를 겹쳐 표시하지 않고 선택된 표정 한 세트만 표시합니다. 캐릭터별 원본 표정 ID로 선택하며 정보창과 공간 미리보기에 함께 적용합니다. 현재 10명, 캐릭터별 14~15개 표정을 지원합니다. 표정 선택도 배치 저장·공유에는 포함하지 않습니다.
