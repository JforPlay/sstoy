# 스구하 지원 계산 규칙

2026-11-14 설치 클라이언트에서 읽은 지원 전투 규칙. 게임 파일은 변경하지 않았다.

- 암호화 Hotfix.dll SHA-256: `c004bcec716a477bc59beb6715eb4cfe528e368341c91011be9b474570a671fb`
- 최신 원본: `_16101.ParallelScript`, `ParallelScript_Support`, `SkillScript_Support`, `SkillScript_Ultra`, `Summoned.FangWeiBiao`의 Spawn / Action / Skill / Parallel.
- 동작·장판·타격 시간은 활성 클라이언트 매니페스트로 선택한 번들에서 추출한 `public/data/combat/161.json` 사용.
- 이전 분석본에는 돌파와 P43 궁 준비 상태 감시가 없어서, 최신 DLL을 다시 분석했다. 단순히 이전 캐릭터의 숫자를 치환하지 않았다.

## 연결 범위

지원 스킬과 필살기, 지원 전용 21~33번 잠재력과 공통 41~43번 잠재력, 돌파 1~5 및 공통 능력치 노드.

관측 지점은 기본 1개 / P21 최대 2개. 원본 소환 수명은 11.5초이며 P21로 10초 연장된다. P23은 별도 11.5초 타이머로 우선 제거한다. 설명의 10초와 생성 연출의 1.5초를 임의로 같은 시점으로 처리하지 않는다.

생성 콤보의 `Area` 이벤트에서 초기 선제 공격을 생성하고, 원본 장판 생성 지연 0.5초 뒤 전술 매핑을 생성한다. 관측 지점이 사라지면 해당 지점의 장판과 남은 공격을 제거한다. P23의 반복 선제 공격은 생성 콤보 종료 후 원본 AI의 0.5초 대기를 거친다. P24의 대체 공격은 별도 이벤트 그룹을 사용한다.

P22/P27 승급은 첫 지원 스킬부터 적용하며 최대 4회. 생성 시점 승급 구간에 맞는 장판을 사용한다. 조준 표식은 기본 3초 후 폭발하며 P24는 3스택에서 즉시 3스택을 소모한다. 이전 타이머는 세대 번호로 무효화한다. P28 추가 표식의 동일 목표 제한은 원본의 `> 1초` 조건이다.

P33/P29는 땅 속성 3명 / 정확히 1명 / 그 외를 구분한다. P43은 궁의 SP와 쿨타임을 함께 확인하며, 궁 장판 안 메인 위치로 활성화하는 버프와 별도로 계산한다.

최신 원본의 돌파 필드명에는 역사적인 번호 혼용이 있어 실제 초기화 ID로 연결했다. 2돌파 일반 공격 후 `16196212`, 4돌파 땅 표식 발동 후 팀 `16196211`과 자신 `16196411`이다.

## 검증과 가정

각 잠재력을 단독 실행하고, 전체 잠재력의 0~5돌파를 각각 180초 실행한다. 중첩·지연 폭발·소환물 만료·두 지점 공존·궁 준비 시 버프 제거·속성 대상 필터를 별도로 검증한다.

다른 계산기 캐릭터와 동일하게 정지한 단일 보스를 전제로 한다. 소환 위치는 메인 전방 3m, 해당 좌표와 보스 거리로 장판 범위를 검사한다. 지형에 막혀 실제 소환 좌표가 달라지는 경우와 보스 이동은 재현하지 않는다. 인게임 피해 로그와의 수치 대조를 끝냈다는 뜻은 아니다.
