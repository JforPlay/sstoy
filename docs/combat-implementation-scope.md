# 전투 계산기 작업 범위

사용자가 지정한 역할만 추가 구현한다. 이미 연결된 역할은 유지하며, 목록 밖의 역할을 먼저 확장하지 않는다. 연결 여부와 실전 검증 완료는 구분한다.

## 우선순위

현재 사용자 지정 작업: 지원 안즈(123)·프리지아(125), 메인 나노하(119)·시아(155). 샤통(114)·플로라(126) 연결은 유지한다.

1. 지원 토나 (130)
2. 지원 윌로(여름) (160)
3. 지원 라루(이브) (158)
4. 지원 안즈 (123)

위 네 역할의 원본 스킬·잠재력·돌파·SP·쿨타임 규칙 연결 및 회귀 테스트를 우선한다.

## 이번 연결 대상

- 메인: 나노하(119), 시아(155)
- 지원: 프리지아(125), 안즈(123)

피렌(110)·치토세(144)·샤통(114)·플로라(126)의 기존 연결은 유지한다. 위 네 역할은 아래 개별 실행 규칙과 검증을 사용한다.

## 기존 연결 유지

- 지정된 메인: 엘리, 후유카, 나즈나, 스파클, 레이스, 세이나(기원), 카린
- 지정된 지원: 그레이, 크루니스(새해), 나츠카, 엘레노어, 틸리아, 호타루, 코제트, 오토하

다른 기존 구현도 삭제하지 않는다. 예시 파티를 사용자 입력 대신 고정하지 않는다.

## 샤통 메인·플로라 지원 계산 경로

- 샤통: 일반/강화 일반 공격과 탄약·재장전, 단타/0.5초 차지 사격의 공유 쿨타임, P2 지연 추가 사격, P3 빠른 지속 피해·P4 단계 교체, P6 회수 완료 후 다음 사격의 강화탄, 치명타 스택·초기화, 궁극기 표적·광폭화 및 16개 잠재력을 연결한다. 돌파는 기존 공통 1~5 규칙을 사용한다.
- 단일 보스에서는 원본 ReflectWeapon이 직전 적을 반사 대상으로 제외하므로 반사 횟수를 임의로 보스 추가타로 바꾸지 않는다. P5의 추가 반사는 이 프로필에서 추가 적중을 만들지 않지만 장탄 피해 계수는 적용된다.
- 플로라: 불꽃/잿빛 나비 3개 또는 5개, 메인 불 속성 타격 조건의 P22/P24, 실제 파티 치명타의 P27/P28/P32, P26 주기 검사, 잿빛 나비 자연 만료 후 P30 지연 연사, 불 원소 팀 버프 및 궁극기 알의 P42/P43 조합을 연결한다. 돌파는 기존 공통 1~5 규칙을 사용한다.
- P22가 단일 보스만 발견하면 원본 Self 탄환을 메인 명의로 발사한다. 능력치는 메인, 잠재력 계수는 플로라로 구분한다. 플로라의 명중 후 효과는 원본처럼 파티 타격을 감지한다.
- 공통 엔진에 파티 타격 전 준비·정산 전·실제 치명타 콜백과 타 캐릭터 명의 투사체를 추가했다. 치명타 발동은 고정 시드로 재현하며, 피해량 자체는 기존 기대 피해 계산을 유지한다.
- 현재는 정지한 단일 보스·아군 최대 HP 프로필이다. 적 다수 반사·처치 후 나비 전이, 아군 피격/사망·강제 해제, 실제 이동 손실은 모델링하지 않는다. 인게임 점수 실측 일치 검증과는 구분한다.

## 토나·윌로(여름) 계산 경로

- 지원 스킬·궁극기와 지원/공통 잠재력 21~33, 41~43을 어댑터에서 처리한다. 돌파 1~5는 공통 규칙과 지원 체류 처리에 연결한다.
- 토나: 물 여행가 수에 따른 원본 콤보 분기, 화살 누적/회수, 관통 3회 지연 폭발, 치명타 발동, 편지 드롭, 냉기/동결, 궁극기 장판 연장과 추가 자식 장판 생성을 처리한다.
- 윌로: 데시벨 실제 스택, 회전→직선→연사 우선순위, 50스택 연사 종료, 궁극기 중 체류시간 정지/복귀, 장판 성장·보호막·색 장판 종료 효과를 처리한다. P26 피해는 표식 발동 여행가의 능력치와 윌로의 잠재력 레벨을 구분한다.
- 기준은 `decompiled-current/AIScript/Character/_13001`, `_16001` 원본과 `public/data/combat/130.json`, `160.json`이다.
- `CombatActorScales.json`은 원본 `KR/bin/CharacterSkin.json`의 기본 스킨 ModelScale/10000이다. `export-rotation-rules.mjs`에서 함께 갱신한다.

검증은 개별 효과 단위 테스트, 각 잠재력 단독 180초 실행, 전체 잠재력+0~5돌파 실행, 두 지원 동시 물 파티 실행으로 나눈다. 테스트 통과를 인게임 실측 일치로 표기하지 않는다. 현재 프로필은 정지한 단일 보스와 고정 위치의 여행가를 사용하며, 윌로의 직선/회전 링크는 접촉 유지 조건으로 계산한다. 실제 이동·회피로 인한 명중 손실은 이 검증 범위에 포함하지 않는다.

## 피렌 메인 계산 경로

- 원본 `_11001/{Parallel,SkillScript_NormalAttack,SkillScript_Zhukong_Skill,SkillScript_Ultra,SkillScript_Dodge,Action}.cs`와 `_11000001DarkFs`의 분신 생성·행동·사망 스크립트를 기준으로 한다.
- 일반 공격 4단계, 메인 스킬의 P1 이벤트 그룹, 잠재력 1~13·41~43, 1~5돌파를 연결한다. 원본에서 쓰지 않는 필드나 지원 전용 잠재력은 메인 규칙으로 추가하지 않는다.
- 분신은 전투 시작 초기 능력치를 복사한다. 분신 전용 버프와 이후 돌파 버프는 개별 분신에 적용하며, 본체의 실시간 버프를 다시 상속하지 않는다. 수명·최대 수량·가장 오래된 분신 제거·명령 교체·궁극기 흡수·사망 폭발을 처리한다.
- 분신 피해는 별도 행위자로 기록한다. 본체 전용 추가타·일반 공격 버프·피해 시 버프·SP를 발동하지 않는다. 분신의 어둠 표식 발동은 원본처럼 본체의 표식 발동 경로로 전달한다.
- P5 확률 분기는 설명문의 대상 버프 조건과 달리 원본 코드의 `de_All`을 사용한다. 카운터 증가→상한 도달 시 엄격한 쿨타임 검사→조건부 초기화→추가타 여부 순서를 그대로 보존한다.
- 분신의 명령 공격/사망 폭발은 기존 단일 보스 명중 유지 프로필을 사용한다. 실제 이동·지형·피격 손실 및 인게임 실측 일치까지 검증했다는 의미는 아니다.

## 치토세 메인 계산 경로

- 원본 `_14401`의 일반 공격·일반/강화 스킬 전환·분신·궁극기·잠재력 1~13/41~43과 공통 1~5돌파 규칙을 연결한다.
- 일반/강화 스킬은 충전과 회복 시간을 공유한다. P3 전환 횟수, P4 회복 시간 감소와 0.25초 지연 분신, P9 보스 적중 시 강화 유지, P10 충전 증가를 반영한다.
- 분신 콤보는 독립 재생하되 원본 NO_DAMAGE 매핑으로 본체 피해를 발생시킨다. 일반 소환수 피해를 중복 합산하지 않는다. P6 마지막 타격 스택은 분신 발동 시점에 보존한다.
- 6단계 일반 공격, P1 강화 콤보, P5 스킵·소모·충전, P6 누적, P7 확률·주기·횟수 제한, P8~P13 조건과 궁극기 잠재력, 물 표식의 냉기·동결을 처리한다. 피격 전용 P12는 적 공격 시뮬레이션이 없는 현재 프로필에서는 스킬 사용 시의 경로만 발동한다.
- 정지한 단일 보스 명중 유지 조건이다. 실제 인게임 점수 일치나 이동·회피 손실까지 검증했다는 의미는 아니다.

## 안즈·프리지아·나노하·시아 계산 경로

- 안즈 지원: 장벽 1/3개와 동행 영역 수명, 실제 직사각형 통과 투사체의 계수·속도 변경, 영역 보유/종료 버프, 바람 타격 확률, 궁극기·보호막과 공통 돌파를 연결한다. 고정 위치 프로필에서 발생하지 않은 장벽 이탈·적 탄환 차단 보상을 임의로 부여하지 않는다. 장벽 통과는 발사 시 직선 경로 기준이며, 비행 중 새 장벽과의 충돌은 별도 이동 시뮬레이션 범위다.
- 프리지아 지원: 세 갈래 얼음꽃은 최초 한 개를 공유하므로 기본16/P22 22개다. 같은 시전의 개화/폭발 공격 ID를 각각 공유하고 겹친 꽃 피해를 중복 합산하지 않는다. P27은 꽃마다 종료 위치에 생성한다. 물 표식·냉기·동결, 광폭화 상주 일반 공격, 20스택 시간 상한, P30 시간 연장, 지원/공통 잠재력과 돌파를 연결한다.
- 나노하 메인: 일반 공격 3단계, 두 부메랑의 왕복 및 최대8회 재투척, 파생 탄환·치명타·표식 조건, 2/3분신의 소환·수명·재소환·명령 교체, P10 두 분신 명령 상한과 공통 돌파를 연결한다. 분신은 원본 `useSummonHit=true`에 따라 본체 명의 타격·발사 시 본체 능력치를 사용한다. 피렌의 독립 소환수와 혼동하지 않는다.
- 시아 메인: 백/흑 동행 드론의 1~4단계 명령, 원본 이벤트 그룹의 백색 탄환 분기, 최대3궤도의 백2/흑1 또는 백3/흑1 구성, 생성/종료와 P2 수명 연장, 미사일·20스택 폭발·직전 공격 적중 수·궁극기 쿨타임 조건을 연결한다. 궁극기는 4초 동안 기본40/P43 50회 발사하며 대상 주위 반경4의 고정 시드 산포를 보존한다. 모든 발사를 보스 확정 명중으로 바꾸지 않는다.
- 네 명 모두 해당 역할 잠재력16개와 공통 1~5돌파 경로를 사용한다. 개별 메커니즘 검사와 잠재력 단독/전체·돌파0~5·180초 실행을 구분한다. 정지 단일 보스 프로필의 수치이며, 이동·적 탄환·잡몹 처치·실제 보스 충돌체 체적과 인게임 점수 실측 일치는 검증 범위 밖이다.
