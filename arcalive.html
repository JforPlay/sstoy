빌드 도우미(도자기 공방)
도자기 제작 시 도움되는 정보와 추천 빌드 모음.
캐릭터/레코드 선택, 잠재·스킬 수치 확인, 요약 및 저장 기능이 제공됨

설명을

여행가 - 레코드 - 요약
여행가

캐릭터 선택을 누르고


검색 또는 속성 필터를 통해 원하는 여행가를 골라줘


여행가를 선택했다면

해당 여행가의 스킬 정보나 메인/지원 포지션에 따른 잠재력 등이 표시돼


스킬, 잠재력 레벨을 원하는 만큼 조정해서 총 점수를 확인 할 수 있고


여기의 상세보기 버튼을 누르면 레벨에 따른 계수도 볼 수 있어.


⬇

배지를 고려해서 스킬, 잠재력은 13레벨-9레벨까지 올릴 수 있도록 만들어져있어.


참고할 부분은 파란색 글자는 레벨이 올라도 변하지 않는 수치이고

핑크색 글자(스킬에선 주황)은 레벨에 따라 변하는 변수야.


지원 캐릭터도 메인 캐릭터와 동일하게 설정해주면 돼.


레코드

여행가와 동일하게 메인 레코드, 서브 레코드를 골라줘.


선택 후에, 레코드 돌파 및 레벨에 따른 스탯 확인이 가능해


화면 오른쪽에 튀어나온 소리 버튼을 누르면


보유중인, 혹은 목표로 하는 음표 수를 조절 할 수 있고


그에 따라 멜로디 스킬, 협주 스킬 정보를 확인 할 수 있어.


요약

말 그대로 요약 페이지야. 본인이 여행가, 레코드 탭에서 구성한 도자기를 한눈에 볼 수 있어.

저장할수도 있고, URL 공유를 통해 글을 올리면 일부 빌드는 추천 빌드에 선정해서 올리고 있으니, 많은 연구 부탁해.


참고로  이 버튼을 누르면, 별의 탑 돌때 나오는 질문 정답지가 보여

  의뢰 도우미  
의뢰 도우미
고급 의뢰 편성 자동 배치 도우미.
보유 여행가 기준 최적 조합 계산 및 부족 태그 추천 기능이 포함되어있어

근데 최근 업데이트로 인게임에서도 조합 자동으로 채우기가 생겨서 인게임 내부 기능을 쓰면 더 편하겠지만,
특정 글에서 추가 태그 몇개를 빼먹는다는 얘기가 있더라고. 잘 보고 의뢰를 보내는게 좋을 것 같아.

이게 전체화면이고


왼쪽에 있는 의뢰 목록 중 원하는 의뢰를 클릭해서 골라줘


그리고 오른쪽 상단에 있는 
❤보유 여행가 관리

해당 버튼을 눌러 보유한 여행가를 추가해준 후에


자동 배정을 해주면

보유한 여행가에 맞게 최적의 조합을 추천해줘.


아니면 의뢰에서 캐릭터 추가를 누른 후에


아래 여행가 풀에서 직접 골라서 집어넣을 수도 있고,
  • 이미 포함된 여행가는 청록색, 필요 태그가 존재하는 여행가는 주황색으로 강조돼
  • 필요 없는 여행가는 검정으로



여행가를 배치하고 나면, 바로 아래에 부족한 태그 기준으로 어떤 캐릭터를 먼저 육성하는게 좋은지도 추천해줘.


고급 의뢰 돌리는데 도움이 되길 바라

  자원 도우미  
자원 도우미
캐릭터 및 레코드 성장에 필요한 자원 계산기.
목표 레벨/스킬 설정 후 요구 재료 및 예상 소모량 계산 가능

해당 기능은 너희 로컬에 저장되니, 시크릿 탭에서 보거나 캐시를 지우지 않는다면 계속 두고 확인할 수 있어


+ 여행가 추가

여행가 선택 옆의 이 버튼을 눌러서 여행가를 선택했을 때 


아래의 화면처럼 선택한 여행가의 필요한 자원을 모두 계산해줘

  • 총 스테미나, 자연 회복 기준 소요 일 수 (최고 단계, 고급 의뢰 기준)
  • 승급 아이템(보스 드랍템), 스킬 강화 아이템(카트리지)
  • 주간 보스 재료, 경험치 책, 도라
  • 레벨 별 뱃지까지
내 재료

이 버튼 누르면 가진 재료 포함해서 볼 수 있어


레코드는 위와 비슷한 기능이라고 보면 되고,


한눈에 보기 기능에서는 아래처럼 여행가, 레코드 별 필요 재료를 한번 에 볼 수 있도록 되어있어.
