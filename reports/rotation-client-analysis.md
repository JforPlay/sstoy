소리 요구량으로 현재 메인 레코드의 협주를 재판정하며, 555331이나 최소 소리로 덮어쓰지 않는다. SP/능력치/스킬 레벨/잠재력 레벨 배지는 소유 캐릭터에 적용한다. 메인 레코드 슬롯을 바꿔도 레코드 ID로 효과를 찾으며, 빈 슬롯을 예시 레코드로 채우지 않는다. 설정을 바꾸면 기존 결과/진행 작업을 폐기한다. 지원 돌파 입력도 표시했다. 기존 앱의 80+ 단계는 계산기에서 메인·지원 모두 Lv90으로 해석하고 화면에도 동일하게 표시한다.

브라우저 검증: 동일 입력에서 행운의 소리를 45→99로 변경해 예측 딜 점수 17908→19542 변화를 확인했다. 다운로드 입력에는 실제 돌파 0과 레코드 빈 슬롯이 그대로 남았고, 예시 JSON 요청이 발생하지 않았다. 입력 변경 시 이전 결과 제거도 확인했다.

**남은 제한:** 전투 이벤트 어댑터는 아직 세이나(기원) 메인·호타루/틸리아 지원, 이 세 캐릭터의 검증된 잠재력/돌파 분기 및 3종 메인 레코드만 구현돼 있다. 다른 캐릭터/미지원 분기에는 오류를 표시하며 예시 파티로 대체하지 않는다. 입력 연결 수정은 모든 캐릭터의 전투 규칙 구현 완료를 뜻하지 않는다. 이 범위를 숨기고 범용 계산기 완성으로 보고해서는 안 된다.

### 전체 캐릭터 데이터 확장 및 돌파 분기 추가

출시/노출 상태인 41명 모두의 타이밍과 무기 데이터를 추출했다. `public/data/CombatCharacterIndex.json` 및 `public/data/combat/<캐릭터 ID>.json`으로 분리했고 Worker는 선택한 캐릭터 파일만 읽는다. 246개 역할별 스킬의 원본 클래스 본문 존재를 확인했으며 `reports/combat-character-coverage.json`에 출처 해시와 미구현 상태를 남겼다. 일부 에셋의 불완전한 타입 트리는 경고로 기록했고, 114의 configs 번들은 미발견으로 유지했다. 다른 캐릭터 데이터로 보충하지 않았다.

세이나(기원)의 2돌파 HP/강화 타격, 3돌파 보스 피해, 4돌파 표식 발동 후 8초 버프, 5돌파 HP 조건별 타격 효과를 추가했다. 틸리아는 표식이 있는 목표 타격/메인 궁/자신의 표식 부여/빛 표식 발동/빛 3인 편성의 1~5돌파 이벤트를 연결했다. 호타루는 표식 발동/진입 종료/자신의 타격/빛 표식 부여/보스 상대의 1~5돌파 이벤트를 연결했다. 이 세 명 모두 5돌파로 180초 실행 및 조건별 테스트를 통과했다(전체 149개 테스트).

**41명의 자료 추출은 41명의 실행 어댑터 구현 완료가 아니다.** 나머지 캐릭터의 전투 중 분기 연결은 여전히 남아 있다. 현재 시뮬레이션은 피격을 모델링하지 않으므로 세이나 HP 조건은 전투 내내 HP가 유지되는 가정을 따른다.

### 공통 규칙 우선의 일괄 처리로 전환

캐릭터 하나의 모든 부분을 끝낸 다음 다음 캐릭터로 넘어가는 순서를 중단한다. 전체 41명·246개 역할의 데이터와 원본 참조를 한 번에 목록화하고, 능력치 산술·레벨 참조·SP·쿨다운·스냅샷·지속 시간·중첩 같은 공통 동작은 공통 엔진에서 처리한다. 개별 어댑터에는 조건·대상·전용 자원·폼 전환·소환 행동 등 캐릭터별 차이만 남긴다.

- `npm run combat:audit`: 전체 효과를 동작 유형으로 묶고 `reports/combat-rule-catalog.json`에 공통 규칙과 전용 규칙 검토 대상을 기록한다. 원본 소스에서 숫자가 일치한 항목은 실행이 확인된 규칙이 아니라 별도 후보로 보관한다.
- `applyBuildPassives`: 예시 입력과 실제 화면 입력의 돌파 능력치 노드·음표 처리를 하나로 통일했다. 설명용 Param 문자열보다 공식 EffectId 배열을 우선한다.
- `combat-common-rules.test.ts`: 출시 캐릭터 41명 전원의 0~5돌파 공통 능력치 처리와, 공통 잠재력 효과·조건부 효과의 분류 경계를 일괄 검증한다.
- `npm run combat:verify`: 공통 규칙과 기존 전투 실행 회귀 검증을 한 번에 실행한다. 이 전환 시점 계산기 테스트 174개 및 배포 빌드가 통과했다.

이 일괄 검증은 41명 전원의 180초 전용 메커니즘 완성을 뜻하지 않는다. 공통 산술을 처리할 수 있다는 사실과 해당 효과의 발동 조건까지 연결됐다는 사실을 구분한다. 실제 데이터 참조 누락과 원본 소스의 동명이인 숫자 후보도 분리한다.
